## Claude

`npx age-of-agents` çalıştırma girişimi Claude Code'un otomatik izin sınıflandırıcısı tarafından engellendi (üçüncü taraf bir npm paketini indirip çalıştırmayı içerdiği için). Paket npm'de gerçekten mevcut (age-of-agents@0.8.1), sorun yok — sadece bu ortamda bu tür çalıştırmalar otomatik olarak izin gerektiriyor.

Kendi terminalinizde şunu çalıştırmanız yeterli:

```bash
npx age-of-agents
```

Bu, Claude Code/Codex oturumlarınızı canlı izleyen yerel bir web arayüzü açacak (küçük bir HTTP sunucusu başlatıp muhtemelen tarayıcıda otomatik açılacak). İsterseniz global kurulum için:

```bash
npm i -g age-of-agents
```

Eğer izin verirseniz (ayarlarınıza bir Bash izin kuralı ekleyerek ya da burada onaylayarak) ben de tekrar deneyebilirim — nasıl ilerlemek istersiniz?
